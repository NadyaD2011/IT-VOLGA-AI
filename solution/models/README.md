Сюда кладутся веса обученных моделей (передаются вместе с решением, п. 5 раздела 3):

- `detector.pt`   — детектор знаков (результат `python training/train_detector.py`,
                    по умолчанию копируется best.pt из .runs/det/grz/)
- `crnn.pt`       — распознаватель (результат `python training/train_rec.py`)

Оба файла должны присутствовать в сдаче: жюри запускает решение офлайн и без
доступа к интернету. Пока весов нет, решение работает в демо-режиме:
contour-детектор находит знаки, OCR возвращает нечитанный текст ('#').
