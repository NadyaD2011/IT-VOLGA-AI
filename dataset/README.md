# Dataset: нестандартные ГРЗ РФ (type1 / type1a / type1b / other)

Полуфинал Волга-IT 2026, номинация «Искусственный интеллект и анализ данных».
Датащит собран участником; публикуется под **CC BY 4.0** (файл `LICENSE`).

## Состав и источники

| часть | каталог | источник | лицензия |
|---|---|---|---|
| Синтетика | `images/synthetic/` | скрипт `generator/generate_synthetic.py` (собственная генерация, шрифт DejaVu Sans Bold — свободная лицензия Bitstream Vera) | сгенерировано участником, CC0 |
| Реальные фото | `images/real/` | собственная съёмка (см. `source` в `meta.csv` для каждой строки: own_photo / URL) | own_photo → CC BY 4.0; прочие — только CC0/CC BY |

Для каждого изображения в `meta.csv` заполнены `source` и `license`. Материалы
из закрытых источников не использовались; получение материалов в обход
технических ограничений сайтов не допускалось (п. 6.3.4). Лица людей размыты
утилитой `tools/blur_faces.py` (OpenCV Haar-cascade) перед добавлением кадров;
кадры, где человек — смысловой центр, в датасет не включались (п. 6.3.3).
Изображения отладочного набора организаторов в датасет не включались
(проверено md5-хэшами, п. 6.3.5 — см. `validation_report.txt`, поле
`debug_set_hits`).

## Методика

### Синтетическая часть
1. Знак рисуется по геометрии ГОСТ Р 50577-2018 (520×112 для типов 1/1Б,
   290×170 для 1А, колонка региона + флаг/«RUS»); тексты — допустимые буквы
   A B E K M H O P C T Y X и реально существующие коды регионов, включая
   трёхзначные 125/225/252/323/550/750/797 и т.п.
2. Кадр: фон — процедурная «кормовая ниша» авто / асфальт / боке / щит-экран;
   вклейка через случайную гомографию (перспектива, поворот).
3. Аугментации: дождь, снег, грязь, блик, ночная сцена, motion blur, шум,
   JPEG-сжатие q∈[52,92]; соответствующие флаги пишутся в `conditions`.
4. Полностью воспроизводимо: фиксированный seed (см. `generator/README-запуск`
   ниже) даёт побайтово тот же набор.

   Запуск: `python generator/generate_synthetic.py --dataset . --count 6000 --seed 20260420`

### Реальная часть
* Съёмка парковок/дорог (в т.ч. праворульные авто с двухстрочными 1А и такси 1Б),
  собственные видеозаписи с регистратора; кадры выбирались так, чтобы знак не
  занимал почти весь кадр (это не «кропы», а реальные сцены).
* Разметка: полуавтоматический инструмент `tools/label_assist.py` (участник
  рисует quad, вводит номер и тип; предразметка детектором только ускоряет
  работу — каждую рамку и символ подтверждает человек). Метки хранятся в
  `labels/<stem>.txt` (YOLO-5 + нормированный quad) и в `meta.csv`.

### Формат
`meta.csv` (разделитель `;`): image;plate_num;plate_type;bbox;quad;is_vehicle;
is_synthetic;source;license;conditions — см. раздел 6.2 задания.
Номера: латиница, ВЕРХНИЙ регистр, нечитаемые позиции `#`. Типы:
type1, type1a, type1b, other.

## Статистика
Актуальная сводка — в `STATS.md` (генерируется `python tools/dataset.py stats`).
Объём и распределение по типам/условиям/регионам, доли синтетики и реальных
кадров. Рекомендуемые минимумы задания (150×type1a, 300×type1b, 50×other реальных;
5000 синтетических) достигнуты — см. `validation_report.txt`.

## Валидация
Перед сдачей прогнано:
`python tools/organizers/validate_dataset.py dataset --report dataset/validation_report.txt`
Отчёт лежит в `validation_report.txt` / `validation_report.json`.
